0. 为什么 Base 改变了游戏 — 一张图说清

关键洞察：最优 range 不是固定的，是 gas cost 的函数。Mainnet 上 gas $30/次→必须用宽 range（少 re-mint）；Base 上 gas $0.30/次→应该用窄 range（高 capital efficiency），多 re-mint 也几乎免费。

Base 上的甜点是 ±5%，不是 ±20%。

Base 反直觉的事实：range 窄 = 收益高，因为 gas 不再是约束。±2% 太极端（IL realized 太频繁），±5% 是收益最大化的甜点。 如果你不想每周操作，±10% 是懒人最优。

4. 波动率 → range 宽度 — Base 速查表

两层 pause 触发器：
• 慢 alert（σ_14d > 15% 持续 6h）— 应对持续高波动。一年 ~3-5 天触发。
• 快 fuse（σ_1d > 8% 持续 30 分钟）— 应对突发异动。覆盖 EWMA 反应滞后的 1-2 天 gap。
任一触发即 pause，恢复条件双约束：σ_14d < 6% AND σ_1d < 5% 持续 48h。
对比 mainnet：mainnet σ=4% 用 ±20%；Base σ=4% 用 ±5%。差距 4x。原因：mainnet 必须避免 gas 频繁烧，Base 不用。

6. 五条规则记忆卡（Base 版）

RULE 1
初始 range = ±5%
Base 上窄才赚。±5% 是数学最优，比 ±20% 多 ~15pp APR。如果懒得每周看盘，用 ±10%。
RULE 2
出 range 等 12h
Base 块快（2s），假突破恢复也快。12h 仍在外才算真出，避免 wick 误触发。
RULE 3
看 σ 选新 range
σ 翻倍 → range 翻倍。σ ≤ 4% 用 ±5%；σ ≤ 8% 用 ±12%；σ ∈ (8,15] 用 ±20–25% 防御性 LP。
RULE 4
σ_14d > 15% 或 σ_1d > 8% 暂停
慢 EWMA + 快 fuse 双触发。LP 数学在 σ > 15% 真不如 Aave 时才撤。fuse 防 EWMA 反应滞后。恢复需 σ_14d<6% AND σ_1d<5% 持续 48h。
RULE 5
3 次同向 = 趋势
连续 3 次都向上突破（或都向下）说明趋势成型，停 LP 别再接刀（窄 range 接趋势死得更快）。
