1. 总览 — 系统做什么

持有 Uniswap V3 ETH/USDC 0.05% pool 上的一个 ±5% LP position。当 ETH 价格出 range 持续 12h，自动 re-mint 到当前价 ±5%。每日上限 2 次 re-mint。两层 pause 触发器：σ_14d > 15%（慢 EWMA 持续高波动）或 σ_1d > 8%（快 fuse 突发异动）→ 全转 Aave USDC on Base。恢复需双条件满足。每个事件 Telegram 通知。

组件责任触发频率
scraper.py 读 Base RPC：pool slot0() + position 状态，输出 Prometheus metrics 每 5 分钟（cron 或 systemd timer）
Prometheus 存储时序、计算 14d σ、运行 alert rules 常驻
Alertmanager 路由 alert 到 strategy.py 的 webhook 端点 常驻
strategy.py webhook server。收到 alert → 查 rate limit → 算新 tick → 调 wallet CLI 事件触发
wallet CLI signed broadcast，policy gate（caps + allowlist）兜底 strategy.py 调用
Telegram bot 通知通道（成功 / 失败 / blocked / pause / 早期出 range 提醒） 每事件一条

3. 机器配置 — 跑在哪里

整套 stack 资源消耗很轻，单机 1 vCPU / 1 GB RAM 就够。两个推荐方案：

方案 A（推荐）：Mac mini + OrbStack REC

硬件已有 Mac mini (M4, 16 GB) — 0 增量成本
容器OrbStack（已装）跑 docker-compose 起 Prometheus + Alertmanager
Python 代码原生跑（用 uv），不进容器，方便调试
系统macOS 26.4.1 Tahoe
持续运行pmset -a sleep 0 displaysleep 0 disksleep 0（禁睡眠）；屏保 OK
外部访问不需要 inbound（Telegram outbound only）
风险：Mac mini 偶发重启 / 系统更新会中断 cron + systemd。最坏情况：错过一次 re-mint 窗口，损失 ~$50。可接受。
缓解：每天 Telegram 通知"scraper heartbeat"，超过 30min 没消息 = 系统挂，去看一眼。

方案 B（更稳）：$5/月 VPS

推荐Hetzner CX22（€4.5/月）/ DigitalOcean basic（$6/月）
规格2 vCPU / 4 GB RAM / 40 GB SSD（绰绰有余）
系统Ubuntu 22.04 LTS
位置选离 Base RPC 近的（欧洲 / 美东都行）
访问SSH + Tailscale（可选）
优势：99.9% uptime，物理上隔离个人 LP infra 和工作环境。$60/年 vs $2100/年 LP 收入，可忽略成本。

本文档其余部分按 方案 A（Mac mini + OrbStack） 展开。VPS 路径几乎一样，把 "macOS + brew + launchctl" 换成 "Ubuntu + apt + systemd"。

groups:
  - name: lp
    interval: 60s
    rules:
      # 早期提醒（2h），可选
      - alert: LpOutOfRangeEarly
        expr: wallet_lp_position_in_range == 0
        for: 2h
        labels:
          severity: info
        annotations:
          summary: "Out of range 2h"
          description: "Will re-mint at 12h unless price recovers"

      # 主触发（12h）
      - alert: LpOutOfRange12h
        expr: wallet_lp_position_in_range == 0
        for: 12h
        labels:
          severity: action
        annotations:
          summary: "Re-mint required"

      # 慢：14d EWMA σ 持续高波动 → pause to Aave
      - alert: LpHighVolatility
        expr: |
          stddev_over_time(
            (ln(wallet_lp_pool_price) - ln(wallet_lp_pool_price offset 1d))
            [14d:5m]
          ) > 0.15
        for: 6h
        labels:
          severity: action_pause
        annotations:
          summary: "σ_14d > 15%, suspend LP"

      # 快：单日 σ 突发异动 → 48h fuse pause（覆盖 EWMA lag）
      - alert: LpTailEvent
        expr: |
          stddev_over_time(
            (ln(wallet_lp_pool_price) - ln(wallet_lp_pool_price offset 1h))
            [1d:5m]
          ) > 0.08
        for: 30m
        labels:
          severity: action_fuse
        annotations:
          summary: "σ_1d > 8%, 48h fuse pause"

      # 恢复条件：σ_14d 和 σ_1d 双双回落，持续 48h
      - alert: LpVolatilityNormalized
        expr: |
          (
            stddev_over_time(
              (ln(wallet_lp_pool_price) - ln(wallet_lp_pool_price offset 1d))
              [14d:5m]
            ) < 0.06
          ) and (
            stddev_over_time(
              (ln(wallet_lp_pool_price) - ln(wallet_lp_pool_price offset 1h))
              [1d:5m]
            ) < 0.05
          )
        for: 48h
        labels:
          severity: action_resume
        annotations:
          summary: "vol normalized, safe to resume LP"

scraper.py (~80 行)

"""Pool + position 监控，每 5 分钟跑一次，输出 Prometheus metrics on :9100."""
import os, time, math, json
from web3 import Web3
from prometheus_client import start_http_server, Gauge

BASE_RPC = os.environ["BASE_RPC_URL"]
POOL_ADDR = "0xd0b53D9277642d899DF5C87A3966A349A798F224"  # ETH/USDC 0.05% on Base
POSITION_TOKEN_ID = int(os.environ.get("POSITION_TOKEN_ID", "0"))
NFPM_ADDR = "0x03a520b32C04BF3bEEf7BEb72E919cf822Ed34f1"

# Metrics
g_pool_price = Gauge("wallet_lp_pool_price", "ETH/USDC pool price")
g_in_range = Gauge("wallet_lp_position_in_range", "1 if position in range else 0",
                   ["token_id"])
g_lower = Gauge("wallet_lp_position_lower_price", "Position lower bound price",
                ["token_id"])
g_upper = Gauge("wallet_lp_position_upper_price", "Position upper bound price",
                ["token_id"])

POOL_ABI = json.loads("""[
  {"inputs":[],"name":"slot0","outputs":[
    {"name":"sqrtPriceX96","type":"uint160"},
    {"name":"tick","type":"int24"}, ...]}
]""")

NFPM_ABI = json.loads("""[{"inputs":[{"name":"tokenId","type":"uint256"}],
  "name":"positions","outputs":[..., {"name":"tickLower","type":"int24"},
                                     {"name":"tickUpper","type":"int24"}, ...]}]""")

def tick_to_eth_price(tick: int) -> float:
    """V3 tick → ETH/USDC human price."""
    pv3 = 1.0001 ** tick
    return 1e12 / pv3

def scrape_once():
    w3 = Web3(Web3.HTTPProvider(BASE_RPC, request_kwargs={"timeout": 10}))
    pool = w3.eth.contract(address=POOL_ADDR, abi=POOL_ABI)
    nfpm = w3.eth.contract(address=NFPM_ADDR, abi=NFPM_ABI)

    slot0 = pool.functions.slot0().call()
    current_tick = slot0[1]
    current_price = tick_to_eth_price(current_tick)
    g_pool_price.set(current_price)

    if POSITION_TOKEN_ID:
        pos = nfpm.functions.positions(POSITION_TOKEN_ID).call()
        tl, tu = pos[5], pos[6]  # tickLower, tickUpper
        # in-range if tickLower <= current_tick < tickUpper
        in_range = 1 if (tl <= current_tick < tu) else 0
        g_in_range.labels(token_id=POSITION_TOKEN_ID).set(in_range)
        g_lower.labels(token_id=POSITION_TOKEN_ID).set(tick_to_eth_price(tu))  # tu = lower ETH price
        g_upper.labels(token_id=POSITION_TOKEN_ID).set(tick_to_eth_price(tl))  # tl = upper ETH price

if __name__ == "__main__":
    start_http_server(9100)  # /metrics
    while True:
        try:
            scrape_once()
        except Exception as e:
            print(f"scrape error: {e}")
        time.sleep(300)

strategy.py (~150 行)

"""Webhook server。接 alertmanager，按规则算 tick，调 wallet。"""
import os, json, subprocess, uuid, math, datetime as dt
from fastapi import FastAPI, Request
from pathlib import Path
import telegram

STATE_FILE = Path("~/work/lp/state.json").expanduser()
MAX_REMINTS_PER_DAY = 2

app = FastAPI()

def load_state():
    if not STATE_FILE.exists():
        return {"date": str(dt.date.today()), "remints_today": 0}
    s = json.loads(STATE_FILE.read_text())
    if s["date"] != str(dt.date.today()):
        s = {"date": str(dt.date.today()), "remints_today": 0}
    return s

def save_state(s):
    STATE_FILE.write_text(json.dumps(s))

def telegram_send(msg: str):
    # 用 agent-vault 拿凭据
    token = subprocess.check_output(["agent-vault", "get", "lp/telegram/token"]).decode().strip()
    chat_id = subprocess.check_output(["agent-vault", "get", "lp/telegram/chat_id"]).decode().strip()
    bot = telegram.Bot(token=token)
    bot.send_message(chat_id=chat_id, text=msg, parse_mode="Markdown")

def compute_new_ticks(current_eth_price: float, sigma_14d: float):
    """按 σ_14d 选 range 半宽。σ > 15% 走 pause 分支（外层调用前已判断）。"""
    if sigma_14d <= 0.04:
        r = 0.05
    elif sigma_14d <= 0.06:
        r = 0.08
    elif sigma_14d <= 0.08:
        r = 0.12
    elif sigma_14d <= 0.15:
        r = 0.22                    # defensive LP — 仍跑赢 Aave ~2pp
    else:
        return None, None           # σ_14d > 15% → pause (caller handles)

    p_lower = current_eth_price * (1 - r)
    p_upper = current_eth_price * (1 + r)

    # tick = ln(1e12 / price) / ln(1.0001)
    tick_at = lambda p: int(math.log(1e12 / p) / math.log(1.0001))
    # token0=USDC, token1=WETH on Base, tick_lower 对应 ETH 上沿
    tick_lower = (tick_at(p_upper) // 10) * 10
    tick_upper = ((tick_at(p_lower) // 10) + 1) * 10
    return tick_lower, tick_upper

@app.post("/alert")
async def receive_alert(req: Request):
    body = await req.json()
    for alert in body.get("alerts", []):
        if alert["status"] != "firing":
            continue
        name = alert["labels"]["alertname"]

        if name == "LpOutOfRange12h":
            await handle_remint()
        elif name == "LpHighVolatility":
            await handle_pause(reason="σ_14d > 15%（持续高波动）")
        elif name == "LpTailEvent":
            await handle_pause(reason="σ_1d > 8%（tail fuse）", fuse=True)
        elif name == "LpVolatilityNormalized":
            await handle_resume()
        elif name == "LpOutOfRangeEarly":
            telegram_send("⏰ Out of range 2h. Will re-mint at 12h if persists.")
    return {"ok": True}

async def handle_remint():
    # 1. Rate limit
    state = load_state()
    if state["remints_today"] >= MAX_REMINTS_PER_DAY:
        telegram_send(f"🚫 Re-mint blocked: {state['remints_today']}/{MAX_REMINTS_PER_DAY} today")
        return

    # 2. 查当前 pool 价 + 14d σ（从 Prometheus 查）
    eth_price = query_prometheus("wallet_lp_pool_price")
    sigma_14d = query_prometheus("stddev_over_time(...)")  # 见 alert rule 表达式

    # 3. 算新 tick
    tl, tu = compute_new_ticks(eth_price, sigma_14d)
    if tl is None:
        await handle_pause()
        return

    # 4. 计算 amount 平衡（具体公式略，按 V3 比例）
    amount_eth, amount_usdc = compute_balanced_amounts(eth_price, tl, tu)

    # 5. 调 wallet —— 先 remove 旧 position，再 mint 新的
    token_id = int(os.environ["POSITION_TOKEN_ID"])
    request_id = f"lp-cycle-{uuid.uuid4().hex[:8]}"

    r1 = subprocess.run(["wallet", "lp", "remove", str(token_id), "--percent", "100",
                         "--chain", "base", "--broadcast", "--yes",
                         "--request-id", f"{request_id}-remove"],
                        capture_output=True)
    if r1.returncode != 0:
        telegram_send(f"⚠ remove failed: {r1.stderr.decode()[:200]}")
        return

    r2 = subprocess.run(["wallet", "lp", "mint", "ETH", "USDC", "--fee", "500",
                         "--tick-lower", str(tl), "--tick-upper", str(tu),
                         "--amount-a", str(amount_eth), "--amount-b", str(amount_usdc),
                         "--slippage-bps", "50",
                         "--chain", "base", "--broadcast", "--yes",
                         "--request-id", f"{request_id}-mint"],
                        capture_output=True)
    if r2.returncode != 0:
        telegram_send(f"⚠ mint failed: {r2.stderr.decode()[:200]}")
        return

    # 6. 更新 state + 通知
    state["remints_today"] += 1
    save_state(state)

10. Telegram bot 设置（详细）

  7. token + chat_id 存进 agent-vault： 
    agent-vault set lp/telegram/token
agent-vault set lp/telegram/chat_id
  8. 测试：

     -d "chat_id=${CHAT}" -d "text=test from kk lp setup"
